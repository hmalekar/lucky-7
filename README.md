# Lucky Seven

A single-file office party dice game for one player at a time.

Choose Under 7, Exactly 7, or Over 7, enter a virtual-token bet, and roll. Wins return twice the bet, including the original stake. Includes animated dice, recent rolls, a browser-local scorecard, and a next-player reset.

Open index.html in a browser. All CSS and JavaScript are embedded; there are no external dependencies.

The game uses adjusted party outcomes and virtual tokens only.
